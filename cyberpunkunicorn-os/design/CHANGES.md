# Design system in firmware (2026-10-20)

How the Claude Design system in this folder landed in the firmware, and where each
piece lives. Status of the OS roadmap stays in `../SCOPE.md`; this file only maps
design to code.

| Design piece | Firmware | Notes |
|---|---|---|
| Pixel app icons (`icons/build_icons.js`) | `apps/ui/cyber_icons.h` + `cyber_icon.cpp` | Generated by `node icons/gen_firmware.js`. Run-length data, 4.2 KB instead of the 17.6 KB raw grids. Rainbow, A/B frames, sparkles and grid cells animate every 40 ms. Added `spectrum` and `files`. No icon for LED, Light Show or File Share (leaving the menu or Bruce-only). |
| Main menu (one app per page) | patch `0010`, `cyberMainMenuItem()` | Icon at 3 px per cell, magenta arrows, rainbow label from the icon table, page dots. Status bar reads `CU5K` + version, clock on the right. |
| OptionList | patch `0010`, `cyberOptionList()` | Header icon when the title names an app, `< back` top left (touch ESC zone), rows in a rainbow frame, `label: value` split right, `i/n` counter. |
| Synthwave scene, glass panels, sparkles, confetti | `apps/ui/scene.h` | No frame buffer: animations erase with the sky colour of the row and skip keep-outs. |
| DIP switch + hardware guide card | `cyberDipSwitch()`, `cyberHardwareCard()` | Shared with the Hardware app (storage thread). Returns Check again / Open anyway / Back. |
| Option hue lift | `cyberItemColor()` | Hues 200-290 lifted 45% toward white for contrast. |
| Frequency app screens | `apps/frequency/FrequencyMenu.cpp` | Home is "tap anything": member card checks in, any other tag is shown, a blank tag can be programmed from there. Batch programming has no dialogs between tags. Errors use one plain sentence each (`reasonWords()` in `backend.cpp`). |
| BootScene finale | `apps/boot/unicorn_boot.cpp` | Tremble, bank left, rocket over the sun on a rainbow jet, diagonal flood with the tagline. 10 s, any key skips. If the 3.7 KB finale state can't be allocated, the old gallop plays. |

Deliberate differences from the design:

- Light, LED and Light Show icons are not generated: those apps leave the menu.
- Footers stay `KEY action` in grey size 1, also where the design shows touch labels: the touch footer (PREV/SEL/NEXT) is Bruce's.
- Fonts are the device 6x8 bitmap font; the web stand-ins (Press Start 2P, VT323) are design-only.

Size: the skin adds about 21 KB to the linked app objects (measured by linking the
changed objects with `--relax`, no LTO), against the 24 KB budget. Confirm with
`build/app.bin` on a real build. Hardware is untested.
