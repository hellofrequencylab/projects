# aio-board

Firmware and notes for the **AIO Board V1.4** Flipper Zero expansion board
(ESP32-S2-SOLO-2U + CC1101 433 MHz + nRF24L01+).

Hardware facts, switch positions, and the flashing procedure are the canon in
[`CLAUDE.md`](CLAUDE.md). Read it before wiring or flashing anything.

No firmware source here yet — next step is a PlatformIO project targeting
`esp32-s2`.
